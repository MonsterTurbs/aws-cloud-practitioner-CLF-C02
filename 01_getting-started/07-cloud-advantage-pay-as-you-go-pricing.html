07 — Cloud Advantage: Pay-as-you-go Pricing 💳

Reviewer / Study Guide (single-column, A4 print-ready)

🎯 Lecture Goal

Understand why pay-as-you-go pricing is a major cloud advantage, and how it changes costs when your usage is low, average, or spiky.

Big idea ✅ In the cloud, you generally pay for what you use, and you don’t pay for resources you’re not using.

💳 What “Pay-as-you-go” Means

Pay-as-you-go means your bill is tied to actual usage.

  • 🟢 If you have no usage, you generally pay nothing for those usage-based services.
  • 📅 With average usage, you get a more predictable monthly cost.
  • 📈 With peak / spiky usage, you can scale up temporarily and pay more only during that period.
  • 📉 When you return to average usage, you return to that lower cost level.

Note: Some AWS services offer other pricing models too (upfront or subscription-style options), but the core cloud idea is still “pay for what you use.”

📊 Usage Pattern = Cost Pattern

No usage 💤

If you don’t use the resources/services (usage-based), you typically don’t pay for them.

Average usage 📅

Stable usage leads to more predictable costs.

Peak (spiky) usage 📈

Scale up for spikes, then scale down afterward—paying more only when the spike happens.

Simple example 💡 If your website needs 1 server on normal days but 3 servers during a promo event, you can run 3 servers only during the event and drop back to 1 server afterward.

🏢 Fixed Costs vs Variable Costs

The lecture explains that cloud pricing often helps companies because it shifts spending:

  • 🏗️ On-prem data center: more fixed costs (buy hardware, maintain facilities) even if servers are idle.
  • ☁️ Cloud: more variable costs (you pay based on usage).

Beginner note 💡 “Fixed cost” = you pay regardless of usage. “Variable cost” = you pay more when usage increases and less when it decreases.

🏷️ Why Cloud Can Be Cheaper: Economies of Scale

AWS can sometimes offer lower prices because it operates infrastructure for thousands of customers.

  • 📦 AWS buys massive amounts of hardware (servers, storage, networking).
  • 💰 Bulk buying enables discounts from hardware vendors.
  • 🤝 Customers indirectly benefit from those savings (economies of scale).

Key takeaway ✅ As an individual company, you usually can’t buy hardware as cheaply as AWS can—so cloud pricing can be competitive.

🗂️ Key Terms to Remember

Pay-as-you-go Usage-based pricing Spiky workload Scale up / down Fixed costs Variable costs Economies of scale

✅ Quick Self-Check

Q1: What does pay-as-you-go mean?

A: You generally pay only for the resources/services you actually use.

Q2: What happens to costs during a usage spike?

A: Costs can increase while you scale up, then drop again when you scale down.

Q3: What cost shift does the cloud enable?

A: It often shifts from fixed costs (on-prem) to variable costs (usage-based).

Q4: What are economies of scale in this context?

A: AWS buys hardware at huge volumes, gets discounts, and can offer competitive pricing to customers.

📝 Clean Summary

  • Cloud pricing is typically usage-based: pay only when you use resources.
  • Costs adapt to your usage level (none / average / peak).
  • Cloud can reduce wasted spend on idle resources.
  • AWS economies of scale can contribute to lower prices.
