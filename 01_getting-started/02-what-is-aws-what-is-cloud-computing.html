02 — What is AWS? What is Cloud Computing? ☁️

Reviewer / Study Guide (single-column, A4 print-ready)

🎯 Lecture Goal

Explain what AWS is, define cloud computing, and understand the key concepts of on-demand access and pay-as-you-go pricing.

Big idea ✅ AWS owns and runs the physical infrastructure (data centers + servers). You use that infrastructure through AWS services—often with a click or an API call.

🏢 What is AWS?

  • AWS stands for Amazon Web Services.
  • It is a subsidiary of Amazon (the company behind amazon.com).
  • AWS doesn’t sell physical products (books/fridges). It provides cloud computing services.

☁️ What is Cloud Computing?

Cloud computing is the on-demand delivery of IT resources over the internet with pay-as-you-go pricing.

💳 Pay-as-you-go (simple explanation)

  • 💸 You pay for the resources you are using.
  • 🛑 You generally stop paying when you stop using a service.

🏗️ How the Cloud Works (Beginner Mental Model)

  • 🌍 AWS runs data centers around the world.
  • 🖥️ Data centers contain physical servers and networking equipment.
  • 🧑‍💻 As a customer, you typically don’t rent one physical server directly.
  • 🧩 Instead, you use AWS services built on top of that infrastructure.

“Black box” idea 🧰 You request resources (start a server, create storage, create a database). AWS decides which physical machine will power that request—without you needing to manage the hardware.

🧪 Examples Mentioned in the Lecture

1) Virtual Server (EC2 concept) 🖥️

  • You rent a virtual machine (a “slice” of a server).
  • You choose different sizes/specs based on needs and cost.
  • Useful when you want a server you can configure (OS, software, settings).

2) AWS Lambda (run code) ⚡

  • You upload code and define when it should execute.
  • AWS manages servers, operating system, scaling, and availability.
  • Useful when you want to focus on code, not infrastructure.

✅ Why Cloud is Useful

  • ⚡ Fast: resources are a click/command away.
  • 🎛️ Flexible: scale up/down and remove resources anytime.
  • 🧰 Less maintenance: no need to run your own data center or replace failing hardware.
  • 💸 Cost-friendly: pay only while resources are being used.

🗂️ Key Terms

AWS Amazon Web Services Cloud Computing On-Demand Pay-as-you-go Data Center IT Resources Virtual Machine AWS Lambda

Q1: What does AWS stand for?

A: On-demand delivery of IT resources over the internet with pay-as-you-go pricing.

Q3: Why is the cloud described as a “black box”?

A: You use services and requests; AWS handles the physical machines and infrastructure behind the scenes.

A: Virtual server (EC2 concept) and AWS Lambda.
