12 — AWS Service Categories (Big Picture) 🧭

Reviewer / Study Guide (single-column, A4 print-ready)

🎯 Lecture Goal

Understand how AWS groups its services into categories, why the official product list can feel overwhelming, and which categories this course will focus on for Cloud Practitioner (CLF-C02).

Big idea ✅ AWS has many services. Instead of memorizing a huge list, learn the main categories and what problem each category solves.

🔎 Why the AWS “Products” List Can Feel Overwhelming

  • AWS offers tons of services, grouped into categories on the AWS website.
  • Some services appear in multiple categories (so the list looks bigger than it really is).
  • Some items are more like features of other services, not completely separate “services.”
  • Some services are niche or not important for building most cloud products.

Study strategy 💡 Focus on the categories and the most common “core” services used for cloud applications—and the ones that show up in the CLF-C02 exam.

🧩 The Core Categories Used in This Course

These groups help you think about AWS services based on what they do in a workload:

🖥️ Compute

Purpose: Run applications and workloads in the cloud.

Example 💡 Run a web server, a crawler, or a tool that converts images to PDF.

🗄️ Data Storage

Purpose: Store files and data (different storage services exist for different needs).

Example 💡 Store uploaded images, backups, documents, or logs.

🧱 Databases

Purpose: Run databases in the cloud (for app data, transactions, reporting, etc.).

Example 💡 Store user accounts, orders, and application data in a managed database.

🔗 Application Integration

Purpose: Help workloads/services communicate and work together.

Example 💡 Connect a web app to background jobs or event-driven processing.

🧰 Cloud Management

Purpose: Monitor and manage your AWS environment as it grows.

Example 💡 Track resources, observe usage, and see what changes users/employees are making.

Remember ✅ Each category contains multiple services, but they all solve a similar type of problem.

🚫 Categories Not Deep-Dived Here (And Why)

🏢 Business Applications

Examples mentioned: communication/email tools like an AWS Slack alternative (Chime) or WorkMail (email).

Why not focused: Not important for building cloud products “on top,” and not important for the CLF-C02 exam (as stated in the lecture).

🤖 Machine Learning / AI

AWS has many ML/AI services, but they have separate specialty exams.

Why not focused: Not part of the core Cloud Practitioner exam scope for this course (you’ll get only a brief overview later).

🧠 What You Should Take Into the Exam

  • Don’t panic when you see a long service list.
  • Think in categories: compute, storage, databases, integration, management.
  • Expect the exam to ask about the right service type for a problem (not obscure services).

Tip ✅ If you can explain what each category is for, you’re already building strong exam intuition.

✅ Quick Self-Check

Q1: Why can the AWS product list look bigger than it really is?

A: Some services appear in multiple categories, and some items are features rather than fully separate services.

Q2: What category is primarily about running applications?

A: Compute.

Q3: Why might you pick different storage services?

A: Different storage services solve different storage needs (files, backups, fast access, etc.).

Q4: Why are Business Applications and ML/AI not a main focus here?

A: They’re less relevant to building cloud products for this exam scope; ML/AI has its own exam focus (per the lecture).
