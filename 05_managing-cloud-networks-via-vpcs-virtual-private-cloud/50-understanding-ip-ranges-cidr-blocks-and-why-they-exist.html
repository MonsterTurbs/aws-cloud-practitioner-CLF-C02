Beginner-friendly notes for AWS Cloud Practitioner (CLF-C02): what CIDR means, why it exists, and how it shows up in VPCs.

📄 Single-column 🖨️ A4 print-ready ✅ Exam-focused 🔐 VPC networking basics

🎯 What you’re seeing in AWS

When working with EC2, VPCs, and related services, you’ll often see an IP-like value with a slash at the end, such as:

172.31.0.0/16
0.0.0.0/0

That slash format is called CIDR notation. It describes a range of IP addresses (not a single IP).

✅ Exam takeaway

x.x.x.x/NN = a network range. The number NN tells you how big/small the range is.

🧱 IP addresses in 60 seconds

An IPv4 address is a 32-bit number. For readability, we write it as four groups (octets) separated by dots:

AAA.BBB.CCC.DDD
  • Each group is 8 bits.
  • So each group can range from 0 to 255.
  • Public IPs must be globally unique on the Internet.
  • Private IPs are used inside private networks (e.g., inside a VPC) and are not routable on the public Internet.
💡 Why private IPs matter

IPv4 has a limited amount of public addresses. Using private IPs inside networks avoids “wasting” public addresses for internal communication.

🧮 CIDR notation explained (the “/16” part)

CIDR notation looks like this:

IP_ADDRESS/PREFIX_LENGTH

The prefix length (the number after the slash) tells you how many bits are fixed (network part). The remaining bits are variable (host part), which is what creates a range.

Rule of thumb ✅

  • Bigger slash number (e.g., /24) = more fixed bits = smaller range 😌
  • Smaller slash number (e.g., /16) = fewer fixed bits = bigger range 😮
Example: 172.31.0.0/16 🧩

/16 means the first 16 bits are fixed. Practically, that usually means the first two octets are fixed (172.31), while the last two can vary:

172.31.0.0  → 172.31.255.255

This is commonly used as a default private range in AWS default VPCs.

Example: 10.0.1.0/24 🧩

/24 means the first 24 bits are fixed. Often the first three octets are fixed (10.0.1), so only the last octet varies:

10.0.1.0  → 10.0.1.255

A /24 is a very common subnet size.

🤓 Optional deeper note (you don’t need to compute ranges for CLF-C02)

IPv4 has 32 bits total. A /16 leaves 16 bits for hosts (2^16 ≈ 65k addresses). A /24 leaves 8 bits for hosts (2^8 = 256 addresses). You typically don’t need to calculate this in the exam—just understand that /24 is smaller than /16.

🌍 What does 0.0.0.0/0 mean?

0.0.0.0/0 is a special CIDR range that means:

⚠️ “All IPv4 addresses”

Because /0 fixes zero bits, everything matches. In security rules, it usually means “allow from anywhere” (the whole Internet).

Example (common in security groups for public web servers):

Inbound: HTTP (80) from 0.0.0.0/0

Best practice: avoid using 0.0.0.0/0 for SSH (port 22). Restrict it to your IP whenever possible.

🏗️ Why CIDR exists in VPCs

A VPC is your virtual network in AWS. When you create a VPC, you assign it a CIDR block (an internal private IP range). AWS then uses that range to assign private IP addresses to resources inside the VPC.

Typical scenario (web + database) 🧠

  • 🌐 Web Server EC2 in a public subnet (reachable from the Internet).
  • 🗄️ Database EC2/RDS in a private subnet (not directly reachable from the Internet).
  • 🔁 They talk to each other using private IPs (from the VPC/subnet CIDR ranges).
✅ Key point

Security Groups can block/allow traffic, but VPC/Subnet design can also remove Internet connectivity entirely for private subnets (stronger boundary).

🔐 Private vs Public IPs (what you should remember)

  • 🏠 Private IP: used inside a private network (e.g., inside a VPC). Not directly reachable from the Internet.
  • 🌐 Public IP: Internet-routable and globally unique. Used when a resource must be reachable from the Internet.
  • 🧩 In AWS, an EC2 instance can have both: private IP (always) + public IP (optional) if placed in a public subnet and configured to receive one.
🧠 Common confusion

“If I allow HTTP in the security group, is it public?” Not necessarily. If the instance is in a private subnet, it still won’t be reachable from the Internet—even if the SG allows it—because there’s no Internet routing path to it.

🧪 Quick Quiz (CLF-C02 style)

  1. What does 0.0.0.0/0 represent?

    Show answer ✅

    All IPv4 addresses (the whole Internet). It means “from anywhere.”

  2. Which is a larger range: /16 or /24?

    Show answer ✅

    /16 is larger. Bigger slash numbers mean smaller ranges.

  3. Why do VPCs use CIDR blocks?

    Show answer ✅

    To define a private IP range so AWS can assign internal addresses to resources (EC2, etc.) and control network routing inside the VPC.

📝 Exam reminders

  • ✅ You do not need to compute CIDR ranges manually for the Cloud Practitioner exam.
  • ✅ You do need to recognize CIDR as “IP range notation” and understand that 0.0.0.0/0 means “anywhere”.
  • ✅ Understand the relationship: VPC → Subnets → routing, and that instances in a VPC typically use private IPs for internal communication.
