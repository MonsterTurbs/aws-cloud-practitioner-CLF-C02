45 — What’s the problem? How do VPCs help? 🧱🌐🔒

Print-ready reviewer (single column, A4) • beginner-friendly notes + examples

🎯 Goal of this lecture

Understand why VPCs exist by looking at a common real-world setup: a public web server that must be reachable from the internet, and a private database that must not be reachable from the internet.

🧩 The simple setup (Web + Database)

Start with one EC2 instance running a web server. Since it serves a website, it needs internet connectivity:

  • ✅ Accept incoming requests (e.g., HTTP)
  • ✅ Send responses back
  • ✅ Optionally download updates / install packages from the internet

Now make it more realistic: add a second EC2 instance running a database. The web app uses that database to store or retrieve data.

Internet 🌐
⬇️ (HTTP/HTTPS)
EC2: Web Server 🖥️
Should be public
⬇️ (DB traffic e.g., TCP 3306/5432)
EC2: Database 🗄️
Should be private

Security risk ⚠️ The database should not accept direct requests from the internet. That is a common attack target.

❓ What problem are we trying to solve?

In this setup, we need fine-grained network control:

  • Web server: reachable from the internet (public access)
  • Database: reachable only from the web server (private/internal access)
  • Both: may still need outbound access for updates/patches (controlled outbound)

In short: not every instance should have the same type of internet exposure. We need to decide who is public, who is private, and how they communicate.

🧯 “But we already have Security Groups… right?”

Yes — when you launch an EC2 instance, you can configure a Security Group. Think of a Security Group as a firewall for the instance (especially for inbound rules).

Security Groups ✅ are important and should always be used to control allowed traffic.

However, this lecture highlights an extra security goal: not only blocking unwanted inbound traffic, but making sure there is no direct internet path to private resources.

Beginner-friendly distinction 👶

  • Security Group: “Traffic can reach me, but I will allow/deny it.” 🚧
  • VPC design (public/private): “There is no direct road from the internet to me.” 🛣️❌

🧱 How VPC helps (conceptually)

A VPC (Virtual Private Cloud) lets you build a controlled network in AWS where you can:

  • Separate resources into public and private areas (subnets)
  • Control how traffic routes (what can reach the internet, and what cannot)
  • Control communication inside the cloud network (web ↔ DB)

Key takeaway ✅ VPC gives you network-level control, not only instance-level firewall rules.
