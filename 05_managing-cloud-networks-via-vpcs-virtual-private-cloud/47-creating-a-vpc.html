🎯 Learning Goals

  • Recognize the role of subnets, Availability Zones, route tables, and the Internet Gateway (IGW).

🗺️ Key Exam Idea: VPC is Regional

VPC is a regional construct. That means:

  • Every region typically starts with a default VPC (e.g., us-east-1, ap-southeast-1, etc.).
  • If you switch the region (top-right dropdown), you are looking at different VPCs.
  • An EC2 instance launched in Region A can only be placed into a VPC that exists in Region A.

🧠 Contrast: Some services (like IAM) are global, so they don’t depend on region selection.

🏗️ Creating a VPC: What You Do in the Wizard

In the AWS Console, go to the VPC service and use the VPC creation wizard. The wizard helps you design your network quickly.

1) Choose how many AZs and Subnets

  • You can decide how many Availability Zones (AZs) are involved.
  • Because subnets are placed inside AZs, choosing AZ count influences your minimum subnet count.

2) Choose Public and Private Subnets

  • Public subnets: intended for resources that need internet connectivity (e.g., a web server).
  • Private subnets: intended for internal resources (e.g., a database) that should not accept inbound internet traffic.

3) Review the Preview Diagram

The wizard shows a network preview (example: 2 public subnets + 2 private subnets). This preview helps you confirm that your layout matches your intended design.

🧭 Route Tables: How Traffic Gets Directed

Inside the VPC, route tables control where network traffic goes.

  • Traffic can be between instances (inside the VPC) or from/to the internet.
  • Route tables tell AWS how to forward requests to the correct target (e.g., IGW, NAT, or local VPC routing).

📌 Simple mental model

Route table = “traffic directions” for the subnet.

  • “Local” routes: let resources inside the VPC talk to each other.
  • “Internet” routes: point to an Internet Gateway.
  • “Private outbound” routes: point to a NAT Gateway.

🌐 Internet Gateway (IGW): What Makes a Subnet “Public”

A subnet becomes “public” when it has a route to the Internet Gateway (IGW).

  • IGW enables internet connectivity for resources in a public subnet (when combined with correct routes and security settings).
  • In the wizard preview, you may see IGW connected to public subnets through route tables.

✅ Example

Web server EC2 instance in a public subnet:

  • Public Subnet route table has a route like: 0.0.0.0/0 → IGW
  • Security Group allows inbound HTTP/HTTPS (if you want a public website).

🔒 NAT Gateway: Private Subnet Outbound Internet Only

A NAT Gateway is used when your private subnet resources need to:

  • ✅ Make outbound requests to the internet (e.g., download updates / patches)
  • 🚫 Still avoid inbound internet-initiated connections directly to them

⚠️ Cost Note (Important)

NAT Gateway typically costs extra and is commonly not Free Tier. Use it intentionally and monitor billing. 💸

🧪 Beginner Example

Database in private subnet:

  • Should NOT accept inbound internet traffic.
  • May need outbound internet for OS/database updates.
  • Solution: put DB in private subnet + use NAT Gateway for outbound-only internet access.

🧱 VPC Endpoints (Mentioned Briefly)

The wizard may offer VPC Endpoints. For now, you can treat this as:

  • 🧩 A way to access some AWS services from inside your VPC without going through the public internet.
  • Not required to create a basic VPC, but you’ll see it again later in the course.

🏷️ DNS Hostnames: Default Names for Instances

The wizard includes settings that ensure instances launched into the subnets can automatically receive:

  • ✅ Hostnames / DNS names (useful for internal communication and basic testing)
  • 🌐 Default addressing that makes it easier to reference instances without memorizing IPs

You can still use your own domain later (Route 53 and related topics), but enabling defaults helps early on.

✅ Quick Check (Self-Quiz)

  1. True/False: VPC is global like IAM. (Answer: False — VPC is regional.)
  2. What makes a subnet “public” in AWS? (Hint: route to IGW.)
  3. Why would you add a NAT Gateway? (Outbound internet for private subnet resources.)
  4. What do route tables do? (They direct traffic—like routing rules.)

🧠 Exam Keywords to Remember

  • VPC = Virtual network in the cloud (regional).
  • Subnet = Sub-division of VPC, placed in an AZ.
  • IGW = Internet Gateway (public internet connectivity).
  • NAT Gateway = Outbound internet for private subnet without inbound exposure.
  • Route Tables = Control where traffic is forwarded.
