🗂️ AWS CLF-C02 Reviewer: EFS vs EBS

Single-page, print-friendly notes on Elastic File System (EFS) and how it compares to Elastic Block Store (EBS).

🎯 Main Idea

After learning EBS (hard drives attached to EC2), the next storage option is EFS. EFS gives you a ready-to-use (pre-formatted) shared file system that can be accessed by multiple compute resources.

Quick memory hook 🧠

  • EBS “Attach a disk to a server” (block storage) 💽
  • EFS “Use a shared folder in the cloud” (managed file system) 📁

📌 What is EFS

EFS (Elastic File System) provides a scalable, pre-formatted file system. Under the hood it uses storage devices, but you don’t manage disk sizing and formatting like you do with EBS.

  • ✅ You can create folders and subfolders (directories) as needed 📂
  • ✅ You interact via command line or application code 💻
  • ✅ Designed for multiple machines/services to access the same files at the same time 👥
  • ✅ Not EC2-only — it can be used with other services (example mentioned: Lambda) ⚙️
  • EFS mindset You manage the file structure (folders/files), AWS manages the storage infrastructure.
  • Common use Shared files for multiple app servers (e.g., user uploads, shared assets).

🆚 EFS vs EBS (Beginner-Friendly Comparison)

Topic EBS (Elastic Block Store) 💽 EFS (Elastic File System) 📁
What you get Unformatted virtual hard drive (block device). You format & mount it yourself. Pre-formatted file system. You immediately create folders/files.
Primary use Extra storage for one EC2 instance (common case). Shared storage for multiple instances/services.
Scaling More manual planning (can scale, but you manage sizing decisions). Built to scale automatically (less worry about “running out of space”).
Multi-attach Possible in some scenarios, but with limitations and careful setup required. Designed for simultaneous access by many clients/services.
Service scope EC2-focused (EBS volumes attach to EC2). Not EC2-only; can be used with other services too.

Simple example 🧩

If you run two EC2 web servers (for high availability) and users upload images, you typically want both servers to see the same uploaded files.

  • EBS is like plugging a hard drive into one server.
  • EFS is like a shared network drive that both servers can use.

🧠 Exam-Oriented Notes (CLF-C02)

  • ✅ Recognize the keywords: block storage (EBS) vs managed file system / shared file system (EFS).
  • ✅ If the question implies “multiple servers need the same files,” think EFS first.
  • ✅ If it implies “attach storage to an EC2 instance,” think EBS.

Common trap ⚠️

Don’t confuse EFS (file system you can structure with folders) with S3 (object storage). In this lecture, the focus is EFS vs EBS.
