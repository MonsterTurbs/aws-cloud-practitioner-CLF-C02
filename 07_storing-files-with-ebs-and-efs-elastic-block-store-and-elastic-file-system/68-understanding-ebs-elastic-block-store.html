🧱 EBS (Elastic Block Store) — Reviewer / Study Guide

✅ EBS in One Minute

Amazon EBS is a service that lets you create virtual hard drives (called volumes) and attach them to EC2 instances (virtual servers). 🖥️💽

  • Think of it like: plugging an extra disk into a server.
  • After attaching: you typically must format and mount it from inside the instance (manual OS work).
  • EBS is EC2-focused: EBS volumes attach to EC2 instances (per the lecture).
🎯 Key takeaway: EBS = block storage. You get a disk-like device. You (or your OS) manage the file system.

🧠 Core Concepts (Beginner-friendly)

Term Meaning (simple)
Volume 💽 A virtual hard drive created in EBS. You attach it to an EC2 instance.
Attach 🔗 Connect the volume to an EC2 instance so the instance can use it.
Format 🧰 Prepare the disk with a file system (e.g., EXT4 on Linux) before you can store files.
Mount 📁 Make the disk accessible at a folder path inside the OS (e.g., /data).
Snapshot 📸 A backup copy of a volume’s data/state that you can use later to restore data.

📦 Why “Block Storage” Matters

Block storage means you’re working with something that behaves like a raw disk. You can build any folder/file structure you want — but you’re also responsible for the setup steps (format + mount). 🛠️

Example: You launch an EC2 instance for a web app. You attach an EBS volume to store uploaded images. You then mount it to a folder like /var/www/uploads so your app can save files there.

🧩 How You Use EBS with EC2

  1. Create or add a volume during EC2 launch (or later after the instance is running). ➕
  2. Connect (SSH / Instance Connect) into the instance. 🔐
  3. Format the volume (first-time use). 🧰
  4. Mount the volume to a directory (so apps can store files). 📁

Note: The lecture emphasizes the manual nature of these steps compared to “managed” storage services.

⭐ Useful EBS Features Mentioned in the Lecture

1) Different volume types (SSD vs HDD) ⚙️

You can choose different disk types optimized for different workloads (e.g., speed vs cost). You don’t need the deep details for CLF-C02, but you should remember that options exist.

2) Elastic volumes (resize) 📈

“Elastic” here means volumes can be scaled (increase size) when you need more storage. You may add a new volume, or resize an existing one.

Example: Your app grows from 50 GB uploads to 120 GB. Instead of migrating to a new disk, you can increase the EBS volume size.

3) Snapshots (backups / restore) 📸

You can create snapshots to preserve data so you can restore it later (useful when instances are terminated or replaced).

  • Use snapshots as a safety net before big changes.
  • Use snapshots to restore data onto a new instance.

4) Multi-Attach (advanced) 🧲

EBS can be attached to multiple EC2 instances in some cases (not all instance/volume types). This is tricky because you must manage file conflicts (two servers writing the same file at the same time).

Exam mindset: Multi-Attach exists, but it’s not the default and requires careful design.

🗺️ Scope and Placement

  • EBS is regional 🌍 — volumes are created in a specific region and you must attach them to EC2 instances in the same region (as highlighted in the lecture).
  • Always confirm your selected region in the AWS console (top-right) before creating resources.

💰 Cost & Safety Reminders

  • EBS volumes can cost money. ⚠️
  • Check the pricing page and the Free Tier quotas/limits before you start using a service.
  • Regularly review your bill and consider budgets/alerts so you don’t spend more than intended.

This aligns with the course’s repeated guidance: always verify pricing and Free Tier limits.

🧪 Quick Examples (Practice Your Understanding)

Example A — “My EC2 needs more disk space”

✅ Use EBS: create a volume → attach to EC2 → format/mount → store files.

Example B — “I’m terminating my instance; I don’t want to lose files”

✅ Create an EBS snapshot first. Later, restore the snapshot to a new volume and attach it to a new instance.

Example C — “Two instances must access the same disk”

⚠️ Consider EBS Multi-Attach (advanced, limited support) and plan for file-write conflicts. In real architectures, shared file access is often handled via other storage patterns/services.

📝 Mini Self-Check (Quick Quiz)

  1. What AWS service gives you “virtual hard drives” attached to EC2? (Answer: EBS)
  2. After attaching a new volume, what two common steps do you perform inside the OS? (Answer: format + mount)
  3. What feature lets you back up and restore volume data later? (Answer: snapshots)
  4. Can you create an EBS volume in one region and attach it to an EC2 instance in another region? (Answer: no; EBS is regional)
