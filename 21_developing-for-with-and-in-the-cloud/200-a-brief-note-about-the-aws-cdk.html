How CDK relates to CloudFormation, what problem it solves, and what you need (and don’t need) for the exam 🙂

✅ Quick Review: CloudFormation vs CDK

Infrastructure as Code Cloud Management Developer Tooling

☁️ CloudFormation (the foundation)

  • 📄 You define AWS resources using templates (JSON or YAML).
  • 🧱 Template describes what to create (VPCs, EC2, S3, IAM roles, etc.).
  • 🔁 You can deploy the same template repeatedly to get a repeatable environment.

🧰 AWS CDK (builds on CloudFormation)

  • 👨‍💻 You define infrastructure using real programming languages (e.g., TypeScript, Python).
  • 🧩 You can use variables, loops, functions, reusable components (called constructs).
  • 🪄 Under the hood, CDK generates a CloudFormation template and deploys it.

Key idea (memorize): CDK is “Infrastructure as Code with a programming language,” but deployment still happens via CloudFormation behind the scenes. ✅

🤔 Why would someone use CDK?

CDK is useful when teams want the benefits of CloudFormation, but prefer writing and maintaining infrastructure using code.

  • 🧱 Reusable building blocks: define a “standard VPC” once and reuse it across projects.
  • 🔁 Less duplication: loops and helpers reduce copy/paste across templates.
  • 🧠 Developer-friendly workflows: use familiar tooling, packages, and code review practices.
  • 🧩 Safer patterns: abstractions (constructs) can encode best practices.

🙂 Think of it like this: CloudFormation is “write a blueprint template.” CDK is “write a program that produces the blueprint.”

💡 Beginner-Friendly Examples

These examples are simplified on purpose. You don’t need to master CDK for CLF-C02, but examples help you remember what CDK is.

Example 1: “Create an S3 bucket” (TypeScript-style)

// PSEUDOCODE (idea only)
import * as cdk from 'aws-cdk-lib';
import * as s3 from 'aws-cdk-lib/aws-s3';

const app = new cdk.App();
const stack = new cdk.Stack(app, 'MyStack');

new s3.Bucket(stack, 'UploadsBucket', {
  versioned: true,
  encryption: s3.BucketEncryption.S3_MANAGED,
});

// CDK will synthesize a CloudFormation template from this.

Example 2: “Create resources using a loop” (Python-style)

# PSEUDOCODE (idea only)
from aws_cdk import Stack
from aws_cdk import aws_s3 as s3

class DataLakeStack(Stack):
    def __init__(self, scope, id):
        super().__init__(scope, id)

        for name in ["raw", "processed", "analytics"]:
            s3.Bucket(self, f"{name}Bucket")

# One loop can create multiple resources cleanly.

What to notice: CDK code looks like normal programming. But the output becomes CloudFormation during deployment. 🪄

🧠 Exam Tips (CLF-C02)

  • ✅ Know that CloudFormation is the core Infrastructure as Code service.
  • ✅ Know that CDK builds on CloudFormation and generates templates under the hood.
  • ✅ Know that CDK is developer-oriented (requires coding knowledge).
  • ✅ For the exam: CDK is optional—you typically only need a high-level understanding.
