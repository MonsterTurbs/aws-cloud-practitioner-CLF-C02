🖥️ What Is “Compute” (Beginner-Friendly)

Compute means the ability to run software using CPU and memory—like “renting a computer” in the cloud.

Simple analogy 💡

Think of compute like renting a workstation. Instead of buying hardware, you rent computing power from AWS and run your app there.

Key concept ✅ In AWS, you pay for compute based on usage (often on-demand), instead of owning the machines.

🏗️ EC2: The “Classic” Compute Service

Amazon EC2 is a major compute service used by many AWS customers. In simple terms, it lets you run a virtual server in the cloud.

What you can do with EC2 ✅

  • Run a web server (e.g., Nginx/Apache)
  • Host an API (Node.js, Python, Java, etc.)
  • Run scheduled jobs or workers (background tasks)
  • Test environments (dev/staging)

What EC2 expects from you ⚠️

  • You manage the OS and installed software (patching, configuration)
  • You must consider security settings and access
  • You pick the instance type (size/capacity)

🧪 Quick Example Scenarios (Easy to Remember)

  1. Website hosting 🌐
    Launch EC2 → install web server → deploy site.
  2. App backend 🚀
    Launch EC2 → run Node.js API → connect to database service.
  3. Batch processing 📦
    Spin up EC2 when needed → process files → shut down to stop paying.
