🎯 What You Must Understand

There are multiple ways to connect to an EC2 instance. In the previous lecture you saw EC2 Instance Connect (browser-based). In this lecture, the focus is on connecting from your local machine using SSH — which requires a Key Pair.

Exam-ready idea ✅ Local SSH needs a key pair (private key file). Without it, SSH authentication won’t work.

🔌 EC2 Instance Connect vs Local SSH

EC2 Instance Connect (browser) 🌐

  • Connect from inside the AWS console (no local terminal required)
  • Convenient when available
  • Note from lecture: only available when using certain AMIs (e.g., Amazon Linux 2)

Local SSH (your computer) 💻🔑

  • Connect using the ssh command (or an SSH client)
  • Requires a Key Pair created/selected in the Launch Wizard
  • Common for automation, scripting, and day-to-day admin workflows

🔑 Key Pairs: What They Are (Beginner Friendly)

A Key Pair is an authentication mechanism for SSH:

  • Private key (a file downloaded to your machine) — keep it secret
  • Public key (stored on/for the instance) — used to verify you

Security ⚠️ If someone steals your private key file, they may be able to access your instance. Store it safely and never share it.

✅ Requirements Checklist for Local SSH

  • Key Pair assigned during launch (or you can’t authenticate) 🔑
  • Security Group allows SSH inbound (port 22), at least from your IP 🔥
  • You know the instance’s Public IPv4 or Public DNS 🌐
  • You have an SSH client installed (e.g., ssh) 🧰

Best practice ✅ For SSH, avoid “from anywhere” in real projects. Prefer restricting inbound SSH to your own IP address.

🧪 Example SSH Command Pattern (Conceptual)

The exact user name depends on the AMI (for Amazon Linux, it’s commonly ec2-user). AWS documentation provides the exact commands and OS-specific steps. 

ssh -i /path/to/your-key.pem ec2-user@<PUBLIC_DNS_OR_PUBLIC_IP>

Reminder ⚠️ This is a pattern for understanding. Always follow the official instructions for your OS/AMI and keep your key permissions secure.

🧰 If You Don’t Have the ssh Command

If you can’t or don’t want to install SSH tools, you can use an alternative client.

  • PuTTY (commonly used on Windows) 🪟
