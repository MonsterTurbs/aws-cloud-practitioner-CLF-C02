🎯 Big Picture: “Compute” Services

AWS has many service categories. In this section we focus on Compute—services that help you run code (apps, websites, jobs) in the cloud.

Exam focus ✅ The three big compute options you should recognize are EC2, ECS/EKS, and Lambda.

🖥️ EC2 (Elastic Compute Cloud)

EC2 is one of the most important AWS services. It allows you to rent a remote server (a virtual machine) running in AWS data centers.

Why EC2 is powerful 💪

  • You can configure the server like it’s your own computer 🛠️
  • You choose the operating system and install any software you need 🧩
  • You can run almost any workload: web server, API, batch jobs, tools, etc. 🌐

Trade-off ⚠️ EC2 gives flexibility, but you also handle more setup/maintenance (OS and software configuration).

📦 ECS & EKS (Containers)

ECS (Elastic Container Service) and EKS (Elastic Kubernetes Service) are compute services for running containerized workloads. They can be an alternative to EC2 when your apps are packaged as containers.

What is a container? (Beginner-friendly) 🧠

A container is a package that includes: (1) your application code + (2) the environment it needs to run. This makes deployments more consistent and reproducible.

Common tooling: Docker 🐳 (popular container technology).

Why ECS/EKS exists ✅ AWS provides a preconfigured environment to run containers, so you don’t have to manually set up a container runtime everywhere.

ECS vs EKS (Simple) 🔍

  • ECS: AWS-native container orchestration
  • EKS: runs containers using Kubernetes (more advanced)

Cloud Practitioner note: You usually only need to recognize that EKS is “Kubernetes on AWS.”

⚡ Lambda (Serverless Compute)

AWS Lambda is a popular serverless compute service. It lets you run code without managing servers or operating systems.

What does “serverless” mean? 🤔

It doesn’t mean “no servers exist.” It means you don’t manage the servers. AWS manages the infrastructure and runtime environment.

How Lambda works ✅ Upload code → tell AWS when to run it (events) → AWS handles the rest.

Beginner example 💡

  • 📁 A file is uploaded to storage → Lambda runs to resize the image
  • 🔔 A scheduled event occurs → Lambda runs a cleanup job

🧭 Quick Comparison (When to Think of What)

Service Best for How much you manage
EC2 🖥️ Maximum flexibility: run almost anything on a VM More responsibility (OS + software setup)
ECS / EKS 📦 Running containers and container clusters AWS manages more; you focus on container deployments
Lambda ⚡ Event-driven tasks, small services, serverless workflows Least management (no servers/OS for you)

🧠 Exam-Focused Notes

  • EC2 is extremely common in questions and real usage ✅
  • ECS/EKS are compute options for containers 📦
  • Lambda is the key serverless compute service ⚡
  • In this course section, we’ll dive deeper into EC2 next 🧩
