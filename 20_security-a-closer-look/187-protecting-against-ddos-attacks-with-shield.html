🛡️ DDoS Protection with AWS Shield (CLF-C02 Reviewer)

Beginner-friendly notes on what DDoS attacks are, why they’re dangerous, and how AWS Shield helps protect your workloads.

🎯 Exam Focus: Security & Network Protection 🧠 Keywords: DDoS, Shield Standard, Shield Advanced 📌 Remember: “Too many normal requests”

1) What is a DDoS attack?

DDoS (Distributed Denial of Service) is an attack where an attacker uses many machines (often a “botnet” of hacked computers) to send massive volumes of requests to your server so it becomes overwhelmed and unavailable.

Key idea (very exam-friendly)

  • The requests can look “valid”: correct ports, no obvious malicious payload.
  • The problem is volume and speed: too many requests in too short a time.
  • This can cause downtime and/or cost spikes (due to autoscaling).

Why firewalls alone may not stop DDoS: WAF/security groups can block bad content or unwanted ports, but DDoS is often “normal” traffic patterns at abnormal scale.

2) Why is DDoS especially painful in the cloud?

Cloud architectures often include load balancers and autoscaling. Those features help with real user spikes, but DDoS can abuse them:

  • Cost risk: your system may scale out to handle the flood → higher compute and bandwidth costs.
  • Availability risk: you might still fail if the attack is bigger than your scaling limits or regional capacity.
  • “Worst of both worlds” scenario: you pay more and users still can’t access the app.

Simple example: Your website normally gets 100 requests/second. A botnet sends 50,000 requests/second. Even if each request is “valid,” your app can slow down or crash.

3) AWS Shield: The DDoS protection service

AWS provides AWS Shield to help protect against DDoS attacks. It comes in two levels:

Shield Level Cost What you get (at a high level) When it makes sense
🛡️ Shield Standard Free + enabled by default
  • Basic DDoS protection
  • Traffic pattern detection for common DDoS signatures
  • Blocks some attacks before they reach your resources
  • Most beginners / small apps
  • General baseline protection
🛡️ Shield Advanced Paid (monthly fee)
  • More advanced protections
  • Customizable protection / rules
  • Anomaly detection (learn your normal traffic and flag abnormal behavior)
  • Access to specialized AWS support for DDoS response
  • High-value / high-risk workloads
  • Large enterprises or critical public-facing apps
  • When downtime is extremely costly

Note: Pricing can change over time. For the exam, focus on the concept: Standard is free and baseline; Advanced is paid and more powerful.

4) Standard vs Advanced: the one-liner memory trick

Shield Standard = “free baseline protection for common DDoS patterns.”

Shield Advanced = “paid, stronger protection + anomaly detection + specialized help.”

What does “anomaly detection” mean here?

It means AWS can learn what “normal” traffic looks like for your workload and detect suspicious spikes or patterns beyond generic DDoS signatures.

5) How Shield fits with other security tools

DDoS protection is usually part of a layered defense strategy:

  • Security Groups / NACLs — control traffic by ports/IP rules.
  • WAF — block malicious web requests by inspecting content (e.g., SQL injection, XSS).
  • Shield — protect availability against high-volume attacks (DDoS).
  • Autoscaling — helps with real spikes (but can increase cost during attacks).

Exam mindset: WAF is about “bad content”; Shield is about “too much traffic.”

6) Quick review checklist

  • DDoS = many sources sending huge request volume → overwhelm service.
  • DDoS requests can be “valid,” so content-based filtering might not help.
  • Shield Standard is free and enabled by default.
  • Shield Advanced is paid and adds stronger protection + anomaly detection + specialized support.
  • Cloud risk: autoscaling can increase cost during attacks.

7) Mini practice questions (self-check)

Q1: Why can a DDoS attack bypass a typical firewall rule set?

A: Because the requests can be valid (correct ports, no malicious payload). The issue is volume, not content.

Q2: Which Shield tier is enabled by default?

A: Shield Standard.

Q3: What’s a key added capability of Shield Advanced?

A: Anomaly detection + more customization and stronger support during DDoS incidents.

Summary

DDoS attacks overload your application with massive request volume. AWS Shield helps defend against these attacks: Standard provides baseline protection for free, while Advanced adds stronger, customizable protections and anomaly detection (paid).
