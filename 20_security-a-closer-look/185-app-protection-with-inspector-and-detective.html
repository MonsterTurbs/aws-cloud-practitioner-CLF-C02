🛡️ App Protection in AWS: Inspector & Detective

CLF-C02 Reviewer • Beginner-friendly notes + examples • A4 print-ready (single column)

🎯 What you must understand (Exam Focus)

Big idea

Security is not only about protecting your AWS account (IAM, MFA, CloudTrail). You must also protect workloads (EC2, containers, etc.) and be able to investigate incidents when suspicious activity happens.

  • Amazon Inspector = find vulnerabilities (before attackers exploit them) 🔍
  • Amazon Detective = investigate incidents (after something suspicious happens) 🕵️

🔍 Amazon Inspector (Vulnerability Scanning)

Amazon Inspector provides automated vulnerability management. When enabled, it scans your workloads for known issues so you can patch and fix problems early.

✅ What it doesAutomatically scans EC2 instances and containers to discover vulnerabilities and surface findings.
🎯 What it helps you answer“Which instances/containers are vulnerable, and what should I patch or remediate?”
🧠 Think of it asA “security health check” for your compute workloads.

Beginner-friendly example

Example: vulnerable software package

You run an app on an EC2 instance. The instance has a software package with a known security issue. Inspector detects the vulnerability and shows:

  • Which EC2 instance/container is affected
  • Which vulnerability was found (and why it matters)
  • Recommended remediation (e.g., apply a patch / upgrade a package)

Goal: fix the issue before it gets abused.

Key takeaway

Inspector is mainly about prevention: continuously finding weaknesses so you can reduce risk.

🕵️ Amazon Detective (Incident Investigation)

Even with strong prevention, suspicious activity can still occur (compromised credentials, exploited vulnerabilities, misconfigurations). Amazon Detective helps you investigate: what happened, when it happened, and what resources were involved.

✅ What it doesAssists with investigating security incidents by exploring activity around AWS resources and surfacing findings.
🎯 What it helps you answer“What actions occurred, which resources were touched, and what timeline explains the incident?”
🧩 Think of it asA guided investigation workspace that gives context and “breadcrumbs” for suspicious activity.

Beginner-friendly example

Example: suspicious outbound traffic

You notice suspicious behavior (e.g., an EC2 instance making outbound requests to an unfamiliar IP address). With Detective, you can:

  • Search and pivot on a resource (user, role, instance, etc.)
  • Review related findings that AWS surfaces for that resource
  • Trace “who/what did what” and build a timeline (dates, resources involved)

Goal: understand impact, fix damage, and prevent recurrence.

Detective vs CloudTrail (common confusion)

🧠 Quick comparison
  • CloudTrail = records AWS API calls (who called what API, when).
  • Detective = helps you investigate incidents by connecting context and surfacing findings. It’s not just “logs”; it’s analysis support.

🧭 When to use which service?

Rule of thumb
  • Prevent issues early → use Inspector 🔍
  • Investigate suspicious activity / incidents → use Detective 🕵️
ScenarioBest fit
“Which EC2 instances have known vulnerabilities?”Inspector
“A workload behaved oddly—what happened?”Detective
“Which user performed suspicious actions?”Detective (and CloudTrail as evidence source)

✅ Quick Review Checklist

  • Inspector = automated vulnerability detection for EC2/containers
  • Inspector findings often point to known package/software vulnerabilities and remediation
  • Detective = incident investigation tool to explore suspicious activity and related findings
  • Detective helps build context: timeline, resources involved, and “what happened”

🧪 Mini Quiz (CLF-C02 style)

  1. Your EC2 instances run software packages with known security issues. Which service helps you discover and remediate these vulnerabilities automatically?
  2. You suspect an EC2 instance is compromised and is communicating with a strange IP address. Which service helps you investigate what happened?
  3. True or False: Inspector is primarily used to investigate incidents after suspicious activity has already occurred.
Show answers ✅
  1. Amazon Inspector
  2. Amazon Detective
  3. False — Inspector focuses on finding vulnerabilities (prevention). Investigation is the role of Detective.

📌 Key Terms to Memorize

  • Vulnerability — a weakness in software/configuration that can be exploited ⚠️
  • Finding — a detected issue/event surfaced by a security service 🔎
  • Remediation — the fix (patch/upgrade/config change) ✅
  • Incident investigation — understanding “what happened” after suspicious activity 🧩
