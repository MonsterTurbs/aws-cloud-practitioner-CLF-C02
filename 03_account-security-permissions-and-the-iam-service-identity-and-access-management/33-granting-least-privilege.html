33 — Granting Least Privilege 🛡️✅

Reviewer / Study Guide (single-column, A4 print-ready)

🎯 What “Least Privilege” Means

Granting least privilege means you should never grant more permissions than needed—to anyone (users, groups, or roles).

Memory hook ✅ Give the smallest set of permissions required to do the job—nothing more.

🚫 Default State: No Permissions

By default, new IAM users and roles have no permissions. They can’t do anything until you attach policies.

Why this is good ✅ It prevents accidental access. You must intentionally grant permissions.

🧾 Policies: Add Only What’s Needed

You grant permissions by attaching policies. Least privilege means:

  • ✅ Attach only the policies needed for that user/role’s tasks
  • ❌ Don’t attach “Full Admin” / AdministratorAccess to everyone

Beginner-friendly example 💡

  • 👀 A user who only needs to view EC2 instances should have a read-only policy
  • 🚀 A user who must start/stop EC2 instances needs additional “write” permissions
  • ❌ Giving admin to both users is risky (too much power)

Risk ⚠️ The more permissions you grant, the bigger the damage if credentials are compromised or misused.

🔑 Manage Programmatic Access Keys (CLI/SDK)

Least privilege also applies to access keys used for programmatic access (AWS CLI & SDKs):

  • ✅ Create access keys only for IAM users who truly need CLI/SDK access
  • ❌ If a user only needs the console, don’t create programmatic keys

Simple rule ✅ No automation needs → no access keys.

👑 Root Account: Best-Practice Reminder

The root account has unlimited access. Best practice is to avoid using it for daily work.

From the lecture ⚠️ If the root account has programmatic access keys, delete them.

Recommended ✅ Use IAM users (even admins) for daily operations, and keep root for rare account-level tasks only.

🧠 Exam-Focused Summary

  1. 1) Least privilege = only necessary permissions 🛡️
  2. 2) New identities start with no permissions 🚫
  3. 3) Attach minimal policies required for the job ✅
  4. 4) Create access keys only when CLI/SDK is needed 🔑
  5. 5) Avoid root usage; remove root access keys 👑
