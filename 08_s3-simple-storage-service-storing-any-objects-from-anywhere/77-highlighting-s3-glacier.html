🧊 Highlighting S3 Glacier — Reviewer / Study Guide

What “Glacier” means in AWS, the 3 Glacier storage classes, and how to recognize them in exam questions.

🧠 Exam note: “Glacier” usually means S3 Glacier 🗄️ Use case: long-term storage, low-frequency access 💰 Benefit: cheaper storage (trade-offs apply)

1) What Is “Glacier”? 🧊

In AWS conversations and exam questions, “Glacier” is sometimes referenced like a standalone service. What it usually means is S3 Glacier — i.e., the archival storage classes in Amazon S3.

✅ Key takeaway (memorize)

S3 Glacier = S3 storage optimized for long-term retention and rare access.

Glacier classes are ideal when you must keep files for months/years (compliance, backups, historical logs), but you don’t open them often.

2) The 3 S3 Glacier Storage Classes 🧾

The lecture highlights these three Glacier options:

Glacier class Best for What you trade off
🧊 S3 Glacier Instant Retrieval Archive data that must still be retrieved fast (but not accessed often) ✅ Very fast retrieval
💸 Retrieval costs apply
💰 Storage cheaper than “hot” tiers
🧊 S3 Glacier Flexible Retrieval
(formerly “S3 Glacier”)		 Backups / DR data accessed 1–2× per year ⏳ Often involves a restore step (minutes to hours)
💸 Retrieval costs apply
💰 Lower ongoing storage cost
🧊 S3 Glacier Deep Archive Compliance archives, “almost never” accessed 🕰️ Slowest retrieval (hours)
💸 Retrieval costs apply
💰 Cheapest long-term storage
🧠 Beginner translation
  • Instant Retrieval = “Archive it, but if I need it, I need it now.”
  • Flexible Retrieval = “I can wait a bit when I need it.”
  • Deep Archive = “I can wait hours; I mostly just need to keep it.”

3) Why Glacier Is Cheaper (Simple Mental Model) 💰

AWS can reduce your cost when it expects low access frequency. The trade-off is typically:

  • 💸 Retrieval fees when you actually read/download the object
  • ⏳ Potential waiting time (restore) for deeper archive tiers
⚠️ Don’t do this

If users or apps need files instantly (e.g., profile images), avoid Glacier Flexible/Deep Archive. Use a frequent-access class instead, or Glacier Instant Retrieval if it truly is archival.

4) Exam Pattern: How to Spot Glacier Questions 🧠

In questions, look for phrases like:

  • 🗄️ “Long-term retention” / “Archive” / “Compliance”
  • 📉 “Rarely accessed” / “Accessed once per year”
  • 💰 “Lowest cost storage”
  • ⏳ “Can wait minutes/hours to retrieve”
✅ Exam tip

If the question says “Glacier” without “S3” — interpret it as S3 Glacier storage class(es) unless the question clearly says otherwise.

5) Quick Examples (Choose the Right Glacier Class) 🧪

  • 📑 Audit documents kept 7 years, accessed rarely → Glacier Deep Archive
  • 💾 Disaster recovery backups, might be needed urgently sometimes → Glacier Flexible Retrieval
  • 🏥 Archived medical images, rare access but must be quick → Glacier Instant Retrieval

6) Mini Reviewer Checklist ✅

  • “Glacier” on the exam usually means S3 Glacier storage classes.
  • Glacier is optimized for long-term storage with low-frequency access.
  • There are 3 classes: Instant Retrieval, Flexible Retrieval (formerly “S3 Glacier”), Deep Archive.
  • Trade-offs: retrieval fees and sometimes restore time.
