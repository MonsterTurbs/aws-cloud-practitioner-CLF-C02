📘 Exam Preparation — Additional Reading (AWS CLF-C02)

Print-friendly reviewer / study guide for extra reading that boosts exam confidence.

🧾 A4 Print-Ready 🧠 Beginner-Friendly 🧩 Single-Column ✅ Focus: Cloud Practitioner

🎯 Goal of this reading list

Watching the course videos and reviewing the slides are the foundation — but you can significantly improve your exam performance by also reading official AWS summaries. These pages are written in a way that mirrors the exam style: short definitions, key benefits, and “when to use which service.”

✅ Best mindset: Don’t aim to memorize every detail. Aim to recognize what a service is for, and how it differs from similar services.

Tip: While reading, keep asking: “What problem does this service solve?” and “What’s the simplest example use case?”

⭐ MUST READ (High impact)

This AWS whitepaper is one of the best single sources to review core concepts and many key services. It also contains services you don’t need for the exam — that’s fine. Focus on the core service summaries.

📄 AWS Overview Whitepaper

What to do: skim the intro + major service categories; then revisit sections where you feel weak (compute, storage, networking, security, billing).

🔗 https://docs.aws.amazon.com/whitepapers/latest/aws-overview/introduction.html

🧠 How to read it efficiently (beginner-friendly)

  • ✅ Read the headings first (treat it like a table of contents).
  • ✅ For each service you see, write one sentence: “I use this when…”.
  • ✅ If you see 2 services that sound similar, add a short “vs” note (example: S3 vs EBS, CloudWatch vs CloudTrail).

🔍 Service overview pages (quick exam-friendly summaries)

Service overview pages are helpful because they usually include plain-language explanations, benefits, and common use cases. These are the kinds of details that show up in multiple-choice questions.

🧭 Example: Trusted Advisor overview page

Focus on: what it checks, why it’s useful, and the categories (cost, performance, security, fault tolerance, service quotas).

🔗 https://aws.amazon.com/premiumsupport/technology/trusted-advisor/

📝 Micro-exercise: After reading a service page, try explaining it like this:

  • “This service is mainly for ____.”
  • “You would choose it when ____.”
  • “It is NOT mainly for ____.”

🌩️ Key marketing / concept pages to study

These pages reinforce the language AWS uses — and the exam tends to reuse that language (benefits, global infrastructure, shared advantages of cloud computing). Reading these makes questions feel more familiar. 🙂

☁️ Core Cloud Concepts

Focus on: what cloud computing is, why it matters, and core terminology.

🔗 https://aws.amazon.com/getting-started/cloud-essentials/

🌍 AWS Global Infrastructure

Focus on: Regions, Availability Zones, Edge Locations; why they matter for reliability and latency.

🔗 https://aws.amazon.com/about-aws/global-infrastructure/

🚀 AWS Benefits (Application Hosting)

Focus on: common cloud benefits (speed, cost, scalability, agility) and examples.

🔗 https://aws.amazon.com/application-hosting/benefits/

✅ Six Advantages of Cloud Computing

Focus on: “trade CapEx for OpEx”, “benefit from massive economies of scale”, “stop guessing capacity”, etc.

🔗 https://docs.aws.amazon.com/whitepapers/latest/aws-overview/six-advantages-of-cloud-computing.html

🏛️ Well-Architected Framework

Focus on: the 6 pillars and what “good architecture” means (operational excellence, security, reliability, performance efficiency, cost optimization, sustainability).

🔗 https://aws.amazon.com/architecture/well-architected/

✅ Simple study plan (no overwhelm)

Use this plan if you want structure without spending endless hours reading.

📅 Suggested flow

  • 1) 📄 Read the AWS Overview whitepaper (skim first, then go deeper only where needed).
  • 2) 🌍 Review AWS Global Infrastructure and Six Advantages pages.
  • 3) 🧭 Read 3–5 service overview pages for services you consistently miss in quizzes.
  • 4) 🏛️ Revisit the Well-Architected Framework pillars — learn the names and the “why”.

Rule of thumb: If a page is long, you’re allowed to skim. The exam tests recognition and understanding, not memorization. 🙂

🧾 Quick checklist (print + tick)

  • ☐ I can explain what a Region and an Availability Zone are.
  • ☐ I know at least 4–6 cloud advantages (and can give a simple example for each).
  • ☐ I can explain the 6 Well-Architected pillars in 1 sentence each.
  • ☐ I can explain what Trusted Advisor does and which categories it checks.
  • ☐ I can say when to use key services (EC2, S3, RDS, IAM, CloudWatch, CloudTrail) and what they are for.

🧩 Mini-quiz (self-check)

  1. Which page helps you understand what you’re allowed to do on AWS? (Hint: acceptable use policy)
  2. Why do Regions and Availability Zones matter for reliability and latency?
  3. What is Trusted Advisor and name two categories it checks.
  4. Name any three of the Well-Architected pillars.
  5. What does “trade CapEx for OpEx” mean in simple words?

✅ Scoring: If you can answer most questions in simple English without reading notes, you’re in good shape.
