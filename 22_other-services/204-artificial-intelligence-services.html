1) Big Idea (What AWS “AI Services” means) 💡

AWS “AI Services” are ready-to-use machine-learning features that you can plug into apps via API. You don’t train your own model (that’s more like SageMaker). Instead, you call a service to do a common task.

Exam mindset: If the question says “need AI feature quickly” (vision, OCR, sentiment, chatbot, speech), think: use an AWS AI Service (managed, pre-trained). ✅

2) Quick Map: Which service solves what? 🧭

Service What it does (simple) Beginner example
Rekognition 📷 Analyze images/videos (objects, faces, labels, moderation) Auto-detect “car”, “person”, “logo”, or detect unsafe content in uploaded photos
Textract 📄 Extract text + structured fields from documents (OCR for forms/tables) Scan an invoice and extract invoice number, total amount, line items
Comprehend 🧠 Understand text (sentiment, entities, key phrases, topics) Analyze product reviews to see if customers feel “positive” or “negative”
Lex 💬 Build chatbots / conversational interfaces (like Alexa-style bots) Customer support chatbot: “Where is my order?” → checks status
Transcribe 🗣️➡️📝 Convert speech/audio to text Turn meeting audio into notes and searchable text
Polly 📝➡️🗣️ Convert text to natural-sounding speech Read articles aloud in a mobile app (accessibility feature)
Translate 🌍 Machine translation of text Translate product descriptions from English → Filipino/Spanish
Fraud Detector 🕵️ Detect suspicious activity / online fraud patterns Flag suspicious transactions: unusual location + high amount + many retries
Personalize 🎯 Real-time personalized recommendations “Recommended for you” products based on clicks and purchases
Forecast 📈 Predict future business outcomes using ML Forecast next month sales using historical sales + seasonality

Memory trick: Rekognition = vision, Textract = documents, Comprehend = text meaning, Lex = chatbot, Transcribe/Polly = speech, Translate = language, Personalize = recommendations, Forecast = prediction, Fraud Detector = fraud.

3) Service-by-service notes (what to remember) 📝

Amazon Rekognition 📷

  • Purpose: Understand what’s in images/videos (labels, faces, objects, moderation).
  • When to choose it: Need vision features without training your own ML model.
  • Example: A social app auto-flags uploaded images that contain unsafe content. 🚫

Amazon Textract 📄

  • Purpose: OCR + extract structured data from forms and tables.
  • Difference vs “simple OCR”: Textract is known for reading documents and pulling out fields (not just raw text).
  • Example: HR scans IDs or forms and extracts name, ID number, and table rows. ✅

Amazon Comprehend 🧠

  • Purpose: Natural Language Processing (NLP): sentiment, entities, key phrases, language detection.
  • Example: “The delivery was late and the box was damaged.” → sentiment: negative 😞

Amazon Lex 💬

  • Purpose: Chatbots/conversational interfaces (intents + prompts + responses).
  • Example: “Reset my password” chatbot that collects email and triggers a reset flow. 🔐

Amazon Transcribe 🗣️➡️📝

  • Purpose: Speech-to-text for audio/video.
  • Example: Turn call-center recordings into text so you can search keywords (“refund”, “cancel”). 🔎

Amazon Polly 📝➡️🗣️

  • Purpose: Text-to-speech (TTS).
  • Example: An e-learning app reads quiz questions aloud for accessibility. 🎧

Amazon Translate 🌍

  • Purpose: Translate text between languages (ML-powered).
  • Example: Auto-translate support tickets into English so a global team can respond. 🌐

Amazon Fraud Detector 🕵️

  • Purpose: Detect fraud (commonly for payments, accounts, signups).
  • Example: Flag a transaction if it’s from a new device + new country + unusual purchase size. 🚩

Amazon Personalize 🎯

  • Purpose: Personalized recommendations based on user behavior (clicks, views, purchases).
  • Example: “Because you watched X, you may like Y.” 🍿

Amazon Forecast 📈

  • Purpose: Time-series forecasting (predict future values from historical data).
  • Example: Forecast product demand to avoid overstock/understock. 📦
Common exam clue: If the prompt says “pre-built AI for common task” → pick the matching AI service. If it says “build/train your own model” → consider SageMaker (not an AI service).

4) Mini scenarios (practice) 🎓

Q1. You want to extract table data from scanned invoices.
A: Amazon Textract 📄
Q2. You want a “recommended products” panel personalized per user.
A: Amazon Personalize 🎯
Q3. You want to detect sentiment from customer feedback messages.
A: Amazon Comprehend 🧠
Q4. You want to turn meeting audio into text notes.
A: Amazon Transcribe 🗣️➡️📝
Q5. You need to detect objects in images uploaded by users.
A: Amazon Rekognition 📷
Q6. You want a chatbot for customer support.
A: Amazon Lex 💬
Q7. You want to forecast next month’s sales using past sales data.
A: Amazon Forecast 📈
