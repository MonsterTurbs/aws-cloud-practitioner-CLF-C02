Machine Learning on AWS (Not Exam-Focused)

CLF-C02 reviewer — beginner-friendly overview of how AWS approaches ML/AI, and which services show up in real projects.

🤖 Machine Learning 🧰 Managed vs Self-Managed 🧠 SageMaker ✨ Pre-built AI Services

1) Why ML is “big” on AWS, but not central in CLF-C02

✅ AWS has many Machine Learning (ML) and Artificial Intelligence (AI) services, and the cloud is a strong place to run ML workloads (scalable compute, GPUs, storage).

⚠️ For the Cloud Practitioner exam, ML is typically not a major focus. ML problems are often more about models + data + code than classic cloud architecture topics (networking, server design, multi-tier apps).

🎯 Practical takeaway

Know the three approaches AWS offers for ML/AI: Self-managed compute, SageMaker, and pre-built AI services.

2) The 3 ways to do ML on AWS

Think of this as a decision tree: “How much control do I need?” vs “How fast do I want results?”

🛠️ Option A — Self-managed ML (maximum control)

  • Run ML code on EC2 (your own servers in the cloud).
  • Use EMR if you need a cluster (connected instances) for big data-style processing.
  • Use ECS + containers if you want container-based workloads.
  • You can choose GPU-optimized instances for heavy training (deep learning, big models).
🙂 Best for

Experienced teams that want full control of frameworks, libraries, and the runtime environment.

🧠 Option B — Amazon SageMaker (managed ML platform)

  • Provides managed infrastructure + tools to build, train, test ML models.
  • Supports both: bring your own code (advanced) and more guided/visual workflows (beginner-friendly).
  • Includes features that help with deploying models so other apps can use them.
🙂 Best for

Teams who want ML workflows without manually managing clusters and tooling.

✨ Option C — Pre-built AI services (fastest time-to-value)

  • Use ready-made services that solve common AI tasks without training your own model.
  • Examples of tasks mentioned: face detection, image analysis, text extraction, video captions.
🙂 Best for

When you need a practical AI feature quickly, and a pre-built model is “good enough.”

3) Beginner-friendly examples

🧪 Example 1 — Self-managed training

Scenario: You’re an ML engineer and want full control over your Python environment.

  • Spin up GPU EC2 instances.
  • Install your preferred ML libraries (PyTorch/TensorFlow, etc.).
  • Train a model and store datasets / outputs in cloud storage.

Key idea: you manage most setup decisions, AWS provides scalable compute.

🏁 Example 2 — Use SageMaker to speed up the workflow

Scenario: Your team wants a managed toolchain for training + deployment.

  • Use SageMaker to develop and train models.
  • Deploy the model so your application can call it (e.g., “predict fraud risk”).

Key idea: less infrastructure work, more focus on model + data.

⚡ Example 3 — Use pre-built AI instead of building a model

Scenario: You need image analysis or text extraction, but you don’t want to build ML from scratch.

  • Use an AWS AI service that already has a model under the hood.
  • Send input (image/video/text) and get results (labels, text, captions, etc.).

Key idea: no model training required; you consume AI like an API.

4) Quick memory cues (for fast recall)

  • 🤖 ML on AWS is broad: lots of services, but CLF-C02 focuses elsewhere.
  • 🛠️ EC2/EMR/ECS = do it yourself (control).
  • 🧠 SageMaker = managed ML platform (build/train/deploy).
  • ✨ AI services = ready-made solutions for common tasks (fast results).
✅ Exam mindset

If you see a question about “managed ML platform,” think SageMaker. If you see “I want AI features without training a model,” think pre-built AI services.

5) Quick Check (Q&A)

Use these to test understanding in under 2 minutes.

Q1: What are the 3 broad options for ML/AI on AWS?

Answer: (1) Self-managed compute (EC2/EMR/ECS), (2) managed ML platform (SageMaker), (3) pre-built AI services for common tasks.

Q2: When would you choose EC2 for ML instead of SageMaker?

Answer: When you want maximum control over the environment/frameworks or have an experienced team that prefers custom setup (including GPU instances).

Q3: What is SageMaker in one sentence?

Answer: A managed AWS service that provides infrastructure and tools to develop, train, test, and deploy machine learning models.

Q4: What’s the advantage of pre-built AI services?

Answer: You can solve common AI tasks (image/text/video analysis) without building or training your own machine learning model.
