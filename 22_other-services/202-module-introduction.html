AWS Certified Cloud Practitioner (CLF-C02) — Study Guide

Module 202: Other Services — Introduction

A quick, beginner-friendly overview of AWS service categories that are useful to know, but typically not exam-critical. 📌

Big picture 🧭

By this point in the course, you’ve already seen many core AWS services (compute, storage, networking, security, etc.). This module introduces additional AWS service categories that exist for specialized needs.

Exam note: These services are commonly not emphasized on CLF-C02 because they’re not used by every customer — but you should still recognize the categories.

1) Why this section exists (even if it’s not exam-heavy) 🤝

  • ✅ AWS has many more services than the “core” set used by almost everyone.
  • ✅ Some services are specialized (only certain industries or workloads need them).
  • ✅ Knowing they exist helps you sound credible and pick the right direction later.

Simple idea: Core services = most common. “Other services” = helpful, but not required for every AWS customer. 🙂

2) Service categories you’ll briefly meet 🧩

🤖 Machine Learning (ML)

What it is: Services that help you build, train, and use models for predictions or automation.

Beginner example: A model that predicts customer churn, detects fraud, or classifies images.

Key takeaway: ML is a big topic, and AWS offers many ML services — but CLF-C02 typically only expects awareness that AWS supports ML.

📡 Internet of Things (IoT)

What it is: Services that connect and manage devices (sensors, appliances, vehicles) that send/receive data.

Beginner example: A fridge or sensor sends temperature readings to the cloud for monitoring and alerts. 🧊

Key takeaway: IoT is about device data + secure connectivity + device management.

🏢 Business Applications

What it is: Tools that support business workflows (communication, productivity, customer engagement, etc.).

Beginner example: A company uses a managed service to improve internal collaboration or customer support flows.

Key takeaway: These are often “nice-to-have” depending on the organization’s needs.

🧰 Other specialized services

What it is: AWS also offers many niche services for specific workloads and industries.

Beginner example: A media company needs video workflows; a manufacturing company needs device telemetry; a bank needs advanced governance.

Key takeaway: AWS is broad — you do not need to memorize everything, but you should know it’s an ecosystem.

3) Quick Check (mini-review) ✅

Quick questions

  • ❓ Why might these services be less important for the CLF-C02 exam?
  • ❓ What is the main goal of IoT services (in one sentence)?
  • ❓ What is the main goal of ML services (in one sentence)?

Suggested answers

  • ✅ Because they are more specialized and not used by every AWS customer, so the exam focuses more on core services.
  • ✅ IoT: Connect/manage devices and securely ingest device data into the cloud for processing and actions.
  • ✅ ML: Use data to train or run models that make predictions or automate decisions.

4) Memory cues (fast retention) 🧠

  • 🤖 ML = “Let the system learn patterns from data.”
  • 📡 IoT = “Devices → cloud → insights/actions.”
  • 🏢 Business apps = “Cloud tools that support business workflows.”
  • 🧰 Other services = “AWS has a tool for many niche problems.”
