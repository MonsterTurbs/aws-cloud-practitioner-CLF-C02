🎯 Lecture Goal

Know what the AWS CLI and AWS CloudShell are, how they relate to the Management Console, and what you need (and don’t need) for the Cloud Practitioner exam.

Big idea ✅ For CLF-C02, you don’t need hands-on CLI/SDK skills. But learning the basics helps you explore AWS faster and automate repeatable tasks.

📝 Exam Note (Very Important)

According to the lecture:

  • ✅ For the Cloud Practitioner exam, you don’t need to be able to use the CLI or AWS SDKs.
  • ✅ You also don’t need deep Management Console skills (no hands-on requirement).

Still worth learning 💡 Console/CLI/CloudShell familiarity makes it easier to “play around” with AWS and understand how services are used in practice.

⌨️ Using the AWS CLI (Local Installation)

The AWS Command Line Interface (CLI) lets you run AWS commands from your computer’s terminal instead of clicking in the web console.

📥 Step 1: Install the CLI

Download and install from: https://aws.amazon.com/cli/

  • 🪟 Windows
  • 🍎 macOS
  • 🐧 Linux

🔐 Step 2: Configure the CLI

After installing, you configure it by running:

aws configure

This configuration uses Access Keys so the CLI can authenticate “behind the scenes” and act on your AWS account.

Beginner mental model 💡 The CLI needs credentials because AWS must know which account and which user permissions are making the request.

🗝️ Access Keys: Where to Create Them

Per the lecture, you can create an Access Key and a Secret Access Key in the Management Console:

  • Click your account name (top-right corner)
  • Choose Security Credentials
  • Create Access Keys there

Security reminder ⚠️ Access Keys are sensitive credentials. Treat them like a password and never share them publicly.

Official guide 📚 Configuration quickstart: https://docs.aws.amazon.com/cli/latest/userguide/cli-configure-quickstart.html

☁️ Using CloudShell (No Local Install Needed)

CloudShell is an alternative to installing the CLI on your own machine.

🧭 Where you find it

CloudShell is integrated into the AWS Management Console. You typically open it by clicking the shell icon in the top bar of the console.

✅ Why CloudShell is convenient

  • 🧰 Comes with the AWS CLI pre-installed
  • 🔐 Automatically assumes your user permissions (so you don’t set up local credentials first, in the typical flow described)
  • 💻 Lets you run AWS CLI commands without installing anything locally

Beginner mental model 💡 CloudShell is like a ready-to-use terminal that AWS hosts for you inside the console.

🧠 Quick Comparison (When to Use What)

  • 🖥️ Management Console: best for learning and exploring services visually.
  • ⌨️ AWS CLI (local): best for repeated tasks, scripting, and automation on your own machine.
  • ☁️ CloudShell: best when you want CLI power without installing/configuring locally.

🗂️ Key Terms (Exam Focus)

AWS CLI CloudShell Access Key Secret Access Key aws configure Security Credentials Authentication Permissions

✅ Quick Self-Check

Q1: Do you need CLI skills for the Cloud Practitioner exam?

A: No. Hands-on CLI/SDK knowledge is not required (per lecture).

Q2: What command is used to configure the AWS CLI?

A: aws configure

Q3: What two credential pieces are created for CLI access?

A: An Access Key and a Secret Access Key.

Q4: What is CloudShell?

A: A browser-accessible shell environment inside the AWS Management Console with the CLI pre-installed.

Q5: Why is CloudShell convenient?

A: No local install needed, and it automatically uses your permissions so you can run CLI commands right away.
