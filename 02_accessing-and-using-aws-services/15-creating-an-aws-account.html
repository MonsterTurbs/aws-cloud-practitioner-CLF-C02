15 — Creating an AWS Account 🧾

Reviewer / Study Guide (single-column, A4 print-ready)

🎯 Lecture Goal

Know when an AWS account is required vs optional for this course and the CLF-C02 exam, and understand what to expect during the AWS signup process (credit card requirement + support plan choice).

Big idea ✅ You can pass the Cloud Practitioner exam by learning AWS concepts in theory—but creating an account helps if you want hands-on practice.

✅ Do You Need an AWS Account to Pass CLF-C02?

No, not necessarily. According to the lecture, you can pass the exam by:

  • 🎥 Watching the course videos
  • 📎 Using attached resources
  • 📚 Reading official documentation
  • 🧠 Learning services and concepts in theory

But… 💡 If you want to “play around” with AWS services (hands-on), then you should create an account.

🧭 Where Account Creation Starts

Account creation starts at aws.amazon.com, where you click the signup/create account button and follow the steps.

What you provide ✅ Personal or business details + payment method information.

💳 Credit Card Requirement (Important)

The lecture emphasizes: you cannot create an AWS account without a credit card.

Why AWS asks for a credit card ⚠️

  • 🆓 Some services can be used for free (up to limits).
  • 📈 If you use paid services or exceed free usage quotas, AWS must be able to bill you.

If you don’t have a credit card 💡 You can still complete the course and pass the exam by learning the theory and using the resources.

🆘 Support Plan Choice (Pick the Free Plan)

Near the end of signup, you’ll choose a support plan.

For this course ✅ Choose the Free / Basic support plan.

Paid support plans can include features like:

  • 📞 24/7 hotline support
  • 👤 A personal AWS account manager

Cost reminder ⚠️ Paid plans can be expensive, and costs can depend on your AWS usage.

The instructor notes you’ll revisit support plans later when discussing how to get help in AWS.

🧠 Beginner Checklist (Safe Learning)

✅ If you create an account

  • Pick the free support plan
  • Be cautious with launching paid resources
  • Track usage as you learn (this module covers cost management)

✅ If you don’t create an account

  • Focus on concepts + service categories
  • Use slides/resources and AWS docs
  • You can still pass CLF-C02 (per lecture)

🗂️ Key Terms (Exam Focus)

AWS Account Free Tier Quota / Free Usage Limit Billing Support Plans Basic Support

✅ Quick Self-Check

Q1: Do you need an AWS account to pass CLF-C02?

A: Not necessarily. You can learn the theory via videos, resources, and docs and still pass (per lecture).

Q2: Why is a credit card required for AWS signup?

A: Because if you use paid services or exceed free quotas, AWS must be able to bill you.

Q3: Which support plan should you choose for this course?

A: The free/basic plan.

A: You can practice hands-on and try services directly instead of only learning in theory.
