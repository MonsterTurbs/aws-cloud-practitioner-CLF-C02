23 — Get Help: AWS Support, Health Dashboards & Documentation 🆘📚

Reviewer / Study Guide (single-column, A4 print-ready)

🎯 Lecture Goal

Know where to get help when something goes wrong in AWS and where to learn more. The lecture covers three key resources:

  • 🧑‍💼 AWS Support
  • 🚦 Health Dashboards (Personal & Service)
  • 📖 Official AWS Documentation

Big idea ✅ If services aren’t behaving as expected, first check whether AWS has an outage/issue, then use docs and support to fix your problem.

🧑‍💼 AWS Support (Support Plans)

The lecture reminds you that when you created your AWS account, you selected a support level (support plan). You can change that later.

✅ What support plans affect

  • How much support you get from AWS
  • Whether you pay extra for that support
  • How quickly / deeply AWS can help you

🔝 Higher plans (advanced users)

More expensive plans can include features like a dedicated account manager who can help with problems and usage guidance.

When to contact support ✅ If you have account-related issues or billing problems, reaching out to AWS Support is a valid option.

Beginner note 💡 For learning and getting started, you typically don’t need paid support levels.

🚦 Personal Health Dashboard (Account Health)

AWS provides a dashboard that shows issues that may be affecting your account and the services you use.

🧭 How to open it (per lecture)

  1. 1) In the Management Console, click the bell icon 🔔
  2. 2) Choose Open issues
  3. 3) You’ll be taken to the Account Health Dashboard (also called Personal Health Dashboard)

✅ What it tells you

  • Whether AWS has internal infrastructure problems affecting your account
  • Which services are impacted (only the services you use)
  • Extra details such as expected resolution timing (when available)

Practical workflow ✅ If a service is failing, check the Personal Health Dashboard first to verify whether it’s an AWS-side issue.

🌍 Service Health Dashboard (Global View)

In addition to account-specific health, AWS also provides a broader view: the Service Health Dashboard.

✅ What it shows

  • Current and recent AWS service issues worldwide
  • Status information for services across regions
  • Historical status (past days) to understand if there were outages

Why it matters 💡

Even if your account dashboard is quiet, the global dashboard helps you confirm whether AWS is having broader issues.

Exam awareness ✅ You don’t need deep hands-on skill here, but you should recognize these dashboards as key AWS troubleshooting resources.

📖 Official AWS Documentation (Most Important Learning Resource)

The lecture emphasizes that the official service documentation is one of the best resources for learning AWS and fixing problems.

✅ What you’ll find in docs

  • Service overview: what the service is and what it does
  • How-to guides: configuration and usage steps
  • Tutorials: step-by-step examples
  • Feature references and deeper explanations

✅ Docs exist for all services

Every AWS service has documentation pages for features, configuration, and troubleshooting.

Quick access trick ✅ Search: “AWS <service name> documentation” (example: “AWS EC2 documentation”) to jump directly to the right docs page.

Where to find docs 📌 On aws.amazon.com, documentation can be accessed whether you are logged in or not.

🧠 Troubleshooting Playbook (Simple Steps)

  1. 1) 🚦 Check the Personal Health Dashboard (your account issues)
  2. 2) 🌍 Check the Service Health Dashboard (global AWS issues)
  3. 3) 📖 Read the service documentation (how-to + troubleshooting)
  4. 4) 🧑‍💼 If it’s account/billing related (or still blocked), contact AWS Support

Outcome ✅ This approach helps you avoid wasting time debugging a problem that is actually caused by an AWS outage.

🗂️ Key Terms (Exam Focus)

AWS Support Support Plans Account Manager Billing Issues Personal Health Dashboard Account Health Dashboard Service Health Dashboard AWS Documentation Troubleshooting

✅ Quick Self-Check

Q1: What are the three main help resources introduced?

A: AWS Support, Health Dashboards (Personal & Service), and official AWS documentation.

Q2: How do you open the Personal Health Dashboard?

A: Click the bell icon in the console → Open issues → Account/Personal Health Dashboard.

Q3: What’s the difference between Personal and Service Health dashboards?

A: Personal is about issues that affect your account/services; Service Health is the global view of AWS service status.

Q4: What’s the fastest way to find a service’s docs?

A: Search “AWS <service> documentation”.

Q5: When should you contact AWS Support?

A: For account or billing problems, or when you need AWS assistance to resolve issues.
