Big outcome ✅ You now understand the main access methods, how AWS usage works “behind the scenes,” and how to avoid unexpected charges.

🧑‍💻 Accessing AWS (3 Main Ways)

You learned that there are multiple ways to use AWS services, and each has different use cases.

1) AWS Management Console (Web UI) 🖱️

  • Best for getting started and exploring services
  • No setup beyond an account + a browser

2) AWS CLI (Command Line) ⌨️

  • More advanced
  • Good for repeated tasks and automation

3) AWS SDKs (Programmatic Access) 🧩

  • Write code that controls AWS services
  • Supports automation and infrastructure-as-code style workflows

Behind the scenes ✅ No matter which method you use, they all end up sending commands (API requests) to AWS.

🧾 Pricing, Free Tier & Cost Control

You learned how to avoid paying more than intended by using AWS’s pricing resources and cost monitoring tools.

🔎 Pricing basics

  • Always check service pricing pages before using a service
  • Prices can differ by Region, so select Regions carefully
  • Use the AWS Pricing Calculator to estimate costs

🆓 Free Tier

  • Many services can be free within the first 12 months (within quotas)
  • Some services are always free within limits
  • Always confirm Free Tier quotas/limits before experimenting

Important ⚠️ Free Tier is not unlimited. Going beyond quotas/limits can create charges.

📊 Billing Dashboard + Cost Tools

You learned that monitoring costs should be a regular habit.

Billing Dashboard 🧾

  • Check current month bill before month end
  • See forecast and which services drive costs

Cost Explorer 📈

  • Analyze costs deeply (filters by region, service, tags, etc.)
  • Useful for accounts with multiple services

Budgets 🎯📧

  • Set a monthly target (e.g., $10)
  • Get email alerts (e.g., at 80%)
  • Budgets alert you—they don’t block spending

🆘 Getting Help & Learning More

You learned the primary resources to troubleshoot issues and deepen your AWS knowledge.

AWS Support 🧑‍💼

Support plan levels can be changed. Higher paid levels offer more help (up to an account manager). Useful for account/billing issues and advanced scenarios.

Health Dashboards 🚦

  • Personal Health Dashboard: issues affecting your account
  • Service Health Dashboard: global AWS issues and service status

AWS Documentation 📖

The most important resource for service details, configuration, tutorials, and troubleshooting. Quick method: search “AWS <service> documentation”.

📏 Service Quotas (Limits)

You learned that AWS services have limits (quotas). Some quotas can be increased using the Service Quotas service.

  • Example mentioned: EC2 Elastic IP limit (5 per account in the lecture example)
  • Some limits are hard; some allow increase requests

✅ Quick Self-Check

Q1: Which access method is best for beginners?

A: The AWS Management Console (web UI).

Q2: What do Console, CLI, and SDKs have in common?

A: They all send API commands to AWS behind the scenes.

Q3: What are two key ways to avoid surprise charges?

A: Monitor Billing Dashboard regularly and set Budgets with alerts.

Q4: What should you check before starting a new service?

A: The service pricing page, Free Tier quotas, and the selected Region.

Q5: Where do you look if services are failing unexpectedly?

A: Personal/Service Health Dashboards first, then documentation, and support if needed.
