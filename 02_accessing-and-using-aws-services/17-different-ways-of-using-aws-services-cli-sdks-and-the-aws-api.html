17 — Different Ways of Using AWS Services (Console, CLI, SDKs, API) 🧭

Reviewer / Study Guide (single-column, A4 print-ready)

🎯 Lecture Goal

Understand the three main ways to access AWS services—Management Console, AWS CLI, and AWS SDKs—and the key idea that they all use the AWS API behind the scenes.

Big idea ✅ Console / CLI / SDKs look different, but they all send authorized API requests to AWS under the hood.

1) AWS Management Console (Web Console) 🖥️

The web-based management console is the most common way to get started with AWS.

👍 Why it’s great for beginners

  • 🧭 Easy to navigate (graphical UI)
  • 🌐 No setup required
  • ✅ Only needs a browser + AWS account
  • 🧪 Perfect for exploring services and features

⚠️ Limitation as things get complex

  • 🖱️ Lots of clicking for complex infrastructure
  • 🤖 Automation is difficult / basically not possible via clicking
  • 📈 Not ideal for repeated large-scale tasks

Course note ✅ You will see the console a lot throughout the course because it’s excellent for learning and demos.

2) AWS CLI (Command Line Interface) ⌨️

The AWS CLI lets you run AWS commands from a terminal instead of clicking in a UI.

🧩 Setup requirements (from the lecture)

  • 📥 Install the CLI (download from the AWS CLI website)
  • 🔐 Configure it with security credentials
  • ✅ Credentials are needed so AWS can authorize actions “on behalf of your account”

Beginner mental model 💡 CLI is like the console, but you “type what you want” instead of clicking buttons.

✅ When CLI is useful

  • 🔁 Repeated, well-known tasks
  • 🏗️ Large-scale setups without lots of clicking
  • 🤖 Automation using scripts

Example (conceptual) 🧪

Run a command to list storage buckets, create a server, or deploy resources repeatedly using a script.

Note: For CLF-C02, you don’t need to memorize CLI commands—you just need to understand what the CLI is and why it exists.

3) AWS SDKs (Software Development Kits) 🧑‍💻

AWS SDKs let you write code (in various programming languages) that interacts with AWS services.

  • 🧾 This is programmatic access to AWS.
  • 🏗️ You can manage AWS resources using code, often called Infrastructure as Code (IaC) in the general sense (as a concept introduced here).
  • 🤖 Excellent for automation and complex workflows.

Example from the lecture 💡 A Python script can start a server, install software, run a process, then shut down the server—so you don’t do those steps manually.

✅ When SDKs are useful

  • 🧩 When you need custom logic (if/else decisions, loops, schedules)
  • 🔗 Integrating AWS operations into your application
  • 🤖 Automating repeatable workflows

🔌 The Key Concept Behind All of Them: The AWS API

The lecture emphasizes a super important behind-the-scenes detail:

All three approaches (console, CLI, SDKs) send API HTTP requests to an AWS Application Programming Interface (API) to make AWS “do something.”

In theory, you could send raw requests directly to the AWS API yourself, but the lecture points out this is difficult because you must configure and authorize the requests correctly.

Beginner mental model 💡

Console / CLI / SDKs → (authorized HTTP API requests) → AWS services

📝 What You Need for the Exam (CLF-C02)

  • ✅ Understand the purpose of the console, CLI, and SDKs.
  • ✅ Know that actions are authorized and tied to your AWS account.
  • ✅ Know that they all use the AWS API behind the scenes.
  • 🚫 You do NOT need to manually send API requests or know deep API details for this exam (per lecture).

🗂️ Key Terms (Exam Focus)

AWS Management Console AWS CLI AWS SDK AWS API HTTP Requests Credentials Authorization Infrastructure as Code

✅ Quick Self-Check

Q1: What are the three main ways of accessing AWS in this lecture?

A: The AWS Management Console, AWS CLI, and AWS SDKs.

Q2: Why is the console great for beginners?

A: It’s a graphical UI, easy to navigate, and needs no setup beyond a browser + AWS account.

Q3: Why is the CLI useful for advanced users?

A: It supports repeated tasks and automation via scripts without clicking through the UI.

Q4: What do the console, CLI, and SDKs all do behind the scenes?

A: They send authorized API HTTP requests to the AWS API.

Q5: Do you need to manually send AWS API requests for CLF-C02?

A: No. You just need to understand the concept (per lecture).
