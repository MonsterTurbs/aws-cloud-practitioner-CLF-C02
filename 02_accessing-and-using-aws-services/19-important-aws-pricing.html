19 — Important AWS Pricing Concepts 💸

Reviewer / Study Guide (single-column, A4 print-ready)

🎯 Lecture Goal

Understand common AWS pricing models (especially On-Demand), how to look up pricing, and how to estimate costs using the AWS Pricing Calculator. Also learn key terms like Total Cost of Ownership (TCO).

Big idea ✅ AWS usage generally costs money, and pricing depends on the service, region, and usage units (e.g., per hour, per GB).

💡 Core Reminder: AWS Services Usually Cost Money

AWS is a business—so most AWS services are paid. Pricing varies by service and by how you use the service.

Beginner tip 💡 Don’t guess costs. Always check the pricing page and/or use the Pricing Calculator before running resources for long periods.

🧾 Common AWS Payment Models

AWS offers different payment models depending on the service:

1) On-Demand (Most Common) ⏱️

You pay only for what you use, based on usage.

  • 🖥️ Example: rent a server → pay for each hour it runs
  • ⏹️ Stop it → stop paying (in that basic model example)

Why it’s common ✅ On-demand pricing matches one of the main cloud benefits: flexible usage without long commitments.

2) In-Advance / Upfront Options 💳

For some services/features, you can commit to a certain usage amount and pay upfront to get a discount.

Note: Not available for all services.

3) Subscription Models 🔁

Some offerings charge a regular fee (monthly/yearly).

  • Example from the lecture: AWS Support Plans

Note: Subscriptions are not super common across AWS services overall.

📏 Pricing Units Vary by Service

How AWS charges you depends on the service and what you consume.

  • ⏱️ Some services charge per hour or per time unit (e.g., server runtime).
  • 🗄️ Some services charge per GB stored (e.g., storage services).
  • 📦 Other services can charge per request, per CPU, per feature, etc.

Key point ✅ You must be able to look up service-specific pricing details, because the units and rates vary.

🔎 How to Look Up AWS Service Pricing

The easiest approach described is to search for AWS pricing and open the official pricing pages.

  • Open the general AWS pricing page
  • Navigate to a specific service (e.g., Amazon EC2)
  • Read the pricing for the exact option you plan to use

EC2 pricing example (concept) 🧪

On-demand EC2 pricing can vary based on:

  • 🌍 Region
  • 🧩 Operating system
  • 🖥️ Instance/server type (how powerful it is)
  • 🧠 CPU specifications

Result: different hourly rates depending on your choices.

🧮 AWS Pricing Calculator (Know This for the Exam)

The lecture highlights the AWS Pricing Calculator as a key tool for estimating costs.

✅ What it does

  • Estimates expected costs for selected services
  • Shows an expected monthly cost based on your inputs
  • Lets you compare different payment strategies (when available)

🆓 Can you use it without logging in?

Yes—according to the lecture, it can be used without being logged in.

Beginner tip 💡 Use the calculator before launching services for real—so you understand the “ballpark” monthly cost.

Example (conceptual steps) 🧪

1) Choose a service (e.g., EC2) 2) Select region 3) Pick usage parameters (simple or detailed) 4) Run estimate → see expected monthly cost 5) Compare strategies (if available)

🏷️ Total Cost of Ownership (TCO)

Total Cost of Ownership (TCO) is the total cost of running a workload either:

  • 🏢 On-premises (local data center): hardware + infrastructure + staff + maintenance, etc.
  • ☁️ In the cloud: service usage and related costs

Why it matters ✅ Companies can compare on-prem vs cloud costs to decide where a workload should run.

Pricing Calculator link to TCO 💡 You can estimate cloud costs using the calculator and compare it against your on-prem costs.

⚠️ Practical Reminder: Avoid Surprise Bills

Important ⚠️ It’s easy to spend more than expected if you launch services and forget to stop or delete them (especially when learning).

Q1: What is the most common AWS pricing model mentioned?

Q2: Give two examples of different pricing units.

Q3: What tool should you know for the exam to estimate costs?

A: The AWS Pricing Calculator.

Q4: Name two factors that can affect EC2 pricing in the lecture example.

A: Region, operating system, instance type, CPU specs (any two).

Q5: What does TCO mean?

A: Total Cost of Ownership—the total cost of running a workload in the cloud vs on-premises.
